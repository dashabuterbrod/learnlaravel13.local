## Инициализация нового проекта laravel
## инструкция по мрдификации файла hosts для обхода региональных ограничений Packjist
>при возникновении сетевых тайм-аутов или блокиовок со стороны CDN при выполнении команд ```composer create-project```
> или ``` composer install``` необходимо перенаправить трафик на валидные IP-адреса репозиториев в обход локальнф
> DNS-серверов
1. откройте конфигурационный файл по пути:```C:\Windows|System32\drivers\etc\hosts```
2. вставьте подготовленный блок записей в конец файла:
```text
138.199.37.232 packagist.org
138.199.37.232 repo.packagist.org
```

либо зайдите в настройки OSPanel,перейдите во вкладку "файл HOSTS" и добавьте подготовленный блок записей в конец файла
### 1. Актуализация пакетного менеджера
обновление локального исполняемого файла Composer до последней стабильной версии
``` bash 
composer self-update
```
### 2. инициализация каркаса приложения 
развертывание чистого скелета laravel в текущую рабочую директорию:
```bash 
composer create-project laravel/laravel .
```

Развертывание чистого скелета laravel и создание рабочей директорию:
```bash 
composer create-project laravel/laravel learnlaravel13.local
```
после чего необходимо перейти в директорию с проектом (если вы еще не находитесь в ней)
```bash
cd learnlaravel13.local
```
### 3. конфигурация API-слоя 
Инсталляция  и автоматическая настройка пакета аутентификации (laravel sanctum), а так же генерация базовых маршрутов 
для работы в режиме Stateless API:
```bash
cd artisan install:api
```

### 4. Экспорт конфигурации CORS
публикация конфигурационного файла config/cors.php для управления политиками крос-доменных запросов
(Cross-Origin Resource Sharing):
```bash
php artisan config :publish cors
```


### 5. инициализация символьной ссылки для Storage
создание симлинка из публичной директории public/storage  в изолированное хранилище storage/app/public для обеспечения 
контролируемого HTTP-доступа к медиафайлам:
```bash
php artisan storage:link
```
### 6. маршрутизация веб-сервера (Apache)
Создание или перезапись файла конфигурации .htaccess в корневой директории для перенаправления входящего трафика на фронт-контроллер
public/index.php

```Apache
RewriteEngine On
#перенаправление  всех ходящих HTTP-запросов в публичную директорию public/
RewriteRule ^(.*)$ public /$1 [L]
```

## Развертывание существующего проекта из репозитория 

### 1. клонирование и инициализация зависимостей 
загрузка исходного кода из удалнного репозитория и устпановка backend-зависимостей согласно ```composer.lock```:
```bash
git clone https://github.com/dashabuterbrod/learnlaravel13.git
cd learnlaravel13
composer install
```
### 2. подготовка окружения и генерация app_key (ключа приложения)
```bash
cp .env.example .env
php artisan key:generate 
```

### 3. миграция и сидирование базы данных 
выполнение базовых DDL-скриптов для построенеия структуры таблиц с параллельным наполнением
справочников тестовыми или системными данными (seeders)
```bash
php artisan migrate --seed
```

### конфигурация подключения к СУБД (.env)
параметры интеграции с базой данных MySQL (версии 8.4+) и глобальные настройки сессий в файле .env:
```env
# параметры подключения к СУБД 
DB_CONNECTION=mysql
DB_HOST=127.0.0.1# (либо )
DB
DB
DB
DB
```
